# Friday Workspace Rules: Frontend Web

- **Assigned Specialist**: `friday` (supported by `jarvis`)
- **Framework**: Next.js 14+ (App Router), TypeScript, Tailwind CSS, Redux Toolkit Query
- **Architecture**:
  - `app/`: Routing, metadata & layouts
  - `components/stepper/`: Public customer booking wizard (10 steps)
  - `components/admin/`: Admin dashboard, package manager, and settings
  - `redux/`: API slices, store & state management
- **Standards**: Zero dummy text, 6 UI states on all dynamic components, No-Dead-Button mandate.
